Add your card

Follow these steps so your changes don't overwrite your teammates' work.

  1. Clone the repository

    git clone <repository-url>

  2. Create your own branch

    git checkout -b add-your-name

  3. Edit only your card in index.html

    Replace the placeholder text, then remove is-open from your card.

  4. Commit your change

    git add index.html
    git commit -m "Add Member 4 info"

  5. Push and open a pull request

    git push origin add-your-name

    Then open a pull request on GitHub and ask a teammate to review it.
